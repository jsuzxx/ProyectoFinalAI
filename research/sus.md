# System Usability Scale (SUS)

Se aplica al final de cada ronda. Escala de 1 (totalmente en desacuerdo) a 5 (totalmente de acuerdo). Se alternan ítems positivos y negativos.

1. Creo que me gustaría usar este portal con frecuencia.
2. Encontré el portal innecesariamente complejo.
3. Pensé que el portal era fácil de usar.
4. Creo que necesitaría apoyo técnico para poder usar este portal.
5. Encontré las distintas funciones del portal bien integradas.
6. Pensé que había demasiada inconsistencia en el portal.
7. Imagino que la mayoría de las personas aprendería a usar este portal muy rápido.
8. Encontré el portal muy difícil de usar.
9. Me sentí muy seguro al usar el portal.
10. Necesité aprender muchas cosas antes de poder usar el portal.

## Cálculo
- Ítems impares: puntuación − 1.
- Ítems pares: 5 − puntuación.
- Sumar, multiplicar por 2,5 → rango 0–100.
